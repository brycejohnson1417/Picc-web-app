# Visual system

Light working surfaces support daylight field use. A restrained graphite navigation rail provides a stable edge; warm neutral account surfaces keep content legible. PICC red marks primary action and selection. Semantic route, status and warning colors carry meaning rather than decoration.

Use the portable DESIGN-SYSTEM.md and existing Tailwind/shadcn primitives. System sans typography, tabular numeric data, compact 13–15px controls, 18–22px record titles, subtle 1px dividers and 8–12px radii. Desktop map fills the available window. Mobile keeps familiar bottom navigation and safe-area spacing. Motion is limited to 150–200ms state transitions; no staggered record loading.
